# Frontend

React + TypeScript + Vite dashboard for the AI 3D Digital Twin Security Camera.

## Run

```bash
cd frontend
npm install
npm run dev
```

The Vite dev server proxies `/api` and `/ws` to `http://127.0.0.1:8000`.

Start the backend first.

## Stack

- React 18 + TypeScript
- Tailwind CSS
- Three.js + React Three Fiber
- Recharts
- React Router
